# 📊 Partho Kumar Roy — Data Analyst Portfolio Website

Welcome to the repository for my personal professional portfolio website. This is a modern, high-performance, responsive single-page application built entirely from scratch using semantic HTML5, custom utility-first CSS variables, and native vanilla JavaScript animations.

The site is designed to showcase my academic background, functional tool stack, and end-to-end data pipelines to potential employers, collaborators, and clients.

---

## 🚀 Key Features

*   **Dynamic Scroll Reveal Animations:** Built using a native JavaScript `IntersectionObserver` workflow, components fluidly drift into view from distinct directions (Up, Down, Left, Right) as you explore the page.
*   **Contextual Typewriter Effect:** Features an automated, looping hero banner highlighting my core technical roles and focal domains.
*   **Fully Responsive & Fluid:** Tailored with custom fluid break-points adapting gracefully from multi-monitor setups down to ultra-compact mobile screens.
*   **Modern Glassmorphism UI:** Implements floating, glowing ambient background vectors (`.blob` & `.blob2`) paired with blurred glass headers to maximize readability and contrast.
*   **Direct Contact Integration:** Features explicit action-oriented CTAs routing visitors to instant WhatsApp communication threads and active professional hubs.

---

## 🛠️ Built With

*   **HTML5:** Structured via optimized, semantic DOM architecture for robust SEO crawlability.
*   **CSS3 (Custom Properties):** Styled using unified theme parameters, flexible Flexbox layers, dynamic CSS Grids, and native transition matrices.
*   **Vanilla JavaScript (ES6+):** Programmed cleanly without bulky external animation or structure frameworks to ensure minimal document size and blazing-fast load speeds.
